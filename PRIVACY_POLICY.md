# RouteMate Privacy Policy

**Effective date:** 19.09.2026  
**Developer:** Roman Martynov  
**Contact:** martynovroman517@gmail.com

RouteMate helps users save locations they deliberately select in Google Maps and organize those locations into a route.

## Data handled by the extension

RouteMate processes the name, address, coordinates, Google Maps URL, route order, schedule, execution status, task details, contact details, and notes that the user chooses to save. This information is stored locally in the user’s Chrome browser profile using Chrome storage. The developer does not receive it.

## Data we do not collect

RouteMate does not collect or transmit browsing history, location history, route contents, notes, advertising identifiers, payment information, or analytics events. RouteMate does not sell user data or use it for advertising.

## Data retention and deletion

Saved routes remain in the browser profile until the user clears them, clears extension storage, or removes the extension. RouteMate also provides JSON backup and restore controlled by the user.

## Website access

RouteMate runs only on the Google Maps URL patterns declared in its manifest. It reads the currently open place only after the user presses **Add stop**. It does not automatically collect search results or browsing activity.

## Limited Use disclosure

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

## Changes and contact

Material changes will be posted on the public page hosting this policy and reflected by an updated effective date. Privacy questions may be sent to the support email above.
