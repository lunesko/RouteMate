# Contributing

RouteMate welcomes focused bug fixes and improvements that support its single purpose: organizing user-selected map locations into a route.

## Before a pull request

1. Open an issue describing the user problem.
2. Keep permissions as narrow as possible.
3. Do not add analytics, advertising, automatic scraping, remote executable code, or hidden data collection.
4. Add or update tests.
5. Run `npm test` and `npm run package`.
